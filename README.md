# 나의 비즈니스 대시보드

Next.js App Router, TypeScript, Tailwind CSS, Recharts로 만든 연습용 대시보드입니다.
모든 매출과 고객, 주문은 가상의 데이터이며 외부 API, 데이터베이스, 환경변수를 사용하지 않습니다.
날짜는 보는 사람의 브라우저에서 계산합니다. 화면은 밝은 테마로 고정됩니다.

## 실행

- 필요한 도구 설치: `npm install`
- 내 컴퓨터에서 열기: `npm run dev`
- 배포용 검사: `npm run build`
- 배포용 실행: `npm start`

Vercel에서는 Next.js 기본 설정을 사용합니다.
